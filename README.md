# Michael Anthony Furniture

A website for Michael Anthony Furniture — showcasing handcrafted pieces built to last.

## About

Michael Anthony Furniture is dedicated to crafting high-quality, handmade furniture pieces for homes and businesses.

## Getting Started

Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/JoeTufano22/MichaelAnthonyFurniture.git
cd MichaelAnthonyFurniture
open index.html
```
